# pairwise-clip2d

## 题面（可直接粘贴）

多边形裁剪。约束：矩形裁剪正确；必须支持凹多边形对凹多边形（Weiler-Atherton 思路），输出顶点序稳定；裁剪面积不大于原面积且并集+交集体积守恒（误差 ≤1e-9）；1 万顶点不超过 400 ms；并发裁剪同一输入一致；退化输入要报错。验收：python -m pytest tests -q -k clip。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 大量顶点耗时
- 并发
- 退化为点/线
- 矩形边界
- 非有限坐标

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
